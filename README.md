# DOG-computer
self made DOG computer

硬件大格局：
1.输入设备：键盘。通过双线连接中断处理器最终连接微处理器，中断处理器留有未来更多外接设备的接口。
键盘是很简单的机电转换结构，不配备大型RAM和处理器。
键盘通过双线连接中断处理器，传递“这是哪个键”和“正在按键”两个信号。

2.中继：中断处理器。信号接收端有和键盘同频的时钟，它的意义是波特率和键盘一致，把在一根线上沿时间分布的01信号转为在不同锁存器中沿空间排布的信息（说白了就是串口）。
中断处理器使用小型RAM，配备计数器，通过双端队列存储键盘键入请求，按照队列先入先出的顺序向主机发送中断请求。中断处理器的队列里存了按键对应的8位二进制码（键盘串口发过来的就是这个），同时设有存放队列首尾地址的锁存器。
八位二进制码会经过解码，通过一个中断处理器和主机中间的ROM取出主机中断程序存储位置的32位地址，并发给程序计数器前端的仲裁器参与仲裁。（输入类按键比如abcd1234ABCD=+- [];'>,/?等等是一类，中断程序合为一种，这些按键的8位二进制码直接对应ASCII，会有一个锁存器存放这些码值，到时候中断程序从这里取按键的ASCII码；控制类按键比如回车、删除、Esc、上下左右翻页等等这些每一个对应一个中断程序）同时，如果中断处理器的队列不是空的，中断信号会置1，这会让仲裁器考虑键盘的中断请求。
中断处理器留有其他端口，可以仲裁多个设备的中断请求，并发给微处理器PC（程序计数器）进一步仲裁，并启动中断程序。但目前只有键盘一个输入设备，不考虑多端口问题。

3.微处理器：核心部分，配备我自行设计的RV32I机器指令集所需所有硬件电路，包括程序计数器和仲裁器、很大的8*64K的RAM、译码器、立即数生成器、寄存器、移位器、比较器、算术逻辑运算器（ALU）、条件跳转电路、中断处理电路、各种选择器blablabla。RAM里写好整数乘除法程序、中断处理程序、程序编译程序和程序运行程序、VRAM写入程序（其实就是显示用的渲染程序）、十进制二进制互转的程序，其它程序按需往里加。
注意，这个微处理器只处理RV32I机器指令，所有的可执行的32位指令必然都是这些机器指令其中之一，编译之前写的类似于汇编指令的代码往往也都对应机器指令，比如“ADDI 5 6 16”代表寄存器5的内容加上立即数16赋给寄存器6。除了个别特殊的机器默认的用法，比如文件系统里的FIND RENAME BUILD OPEN CODE RUN，命令行模式里面的CLEAR，这些都是自带的函数，编译程序在编译时会把它们翻译成一串32位指令，而不是一条32位指令。其他的大多数代码直接就是RV32I指令集里的东西，直接翻译成一条机器指令。

4.输出设备：显示器，配备图像译码器和屏幕（8位ASCII码转换成字符的64像素位）。主机RAM里面有一块地方是给显示器访问用的VRAM，硬件构造上和RAM其他区域不太一致， 每一个字节的VRAM都经由图像译码器连着显示器的一个字的位置。但是在逻辑上VRAM的访问和其他RAM的访问都是一样的，直接按照地址去读写就行。
显示器我计划做成每行64字符每列25字符的矩阵，每个字符用8*8点阵显示。

5.永久存储设备（磁盘）：这个东西里面的细节我不好设计了，物理原理比较深，我们这里假设它像RAM一样露出DataIn DataOut AddrIn AddrOut Write这些操作针脚，像RAM一样操作它。磁盘内部存储操作系统（哈哈哈不是什么复杂东西，就是最基本的运行程序）和文件系统（后续有说明）。磁盘和主存RAM可以使用同一种32位地址进行访问（比如00000000h-0000FFFFh归RAM，往后的归磁盘）

关于两个模式：
mode1：文档的读写。
文档存储于硬盘，在逻辑上进行Page分割（实现上可以按照一定的地址间隔进行划分）。只把特定的Page写到RAM文本块区块。切片器默认为一条file[0:]，主机按照切片渲染后写入VRAM，VRAM直接连显示器。
文本块区块参数：末地址（default=文本块+00000000h）
光标位置：光标地址（default=00000000h（相对值））
切片表格式规范示例：[source（是源文件还是文本块） begin end length]（当切片存储超过一定数目，强制把编写的结果写回原文档，然后再次把该页内容传回来，这时就只有一个切片，这是为了防止切片太多存不下）
改写时地址计算：从前到后累加，当累加值超过光标地址，上前一个切片里面算出相应地址。比如切片[源文件 0 8 9][文本块 9 17 9]，光标位于14处，那么算法很显然是0+9=9;9<14继续;9+9=18;18>14;14-9=5;那么光标就位于第1个切片（从0计数）的第5个字符（从0计数）。

基本功能（循环调用等）设计
（1）循环调用：
函数的实质是写在别处的一段代码，通过跳转方式调用。传递实参的过程就是往函数的程序块里写参数，函数返回值的实质也是把值留在程序块的某个地方，要取用的程序过去取用。
实参里面包括返回地址（这个不是用户输入的，这个是系统决定的）
栈：存储函数实参，等待继续使用。

循环调用全过程：
函数实参压栈（有多少个压多少个），传入的新实参替到参数位上，跳转执行。
返回值会写到返回值的槽里，一经返回立即存下。
实参弹栈，挨个取出重新替入参数槽。继续执行直到返回值。
